# RATH GreenOps Cloud — Deployable Vite App

## Upload structure

GitHub root should look like this:

```text
package.json
index.html
vite.config.ts
tsconfig.json
tailwind.config.js
postcss.config.js
src/
  main.tsx
  App.tsx
  index.css
  rath/
    RathGreenOpsCloud.tsx
    domain/
      engine.ts
```

## Local run

```bash
npm install
npm run dev
```

## Vercel

Framework preset: Vite

Build command:
```bash
npm run build
```

Output directory:
```bash
dist
```
